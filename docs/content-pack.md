# Content pack

`content-pack.json` (schema `demo-content-pack/1`) is generated: `node scripts/build-content-pack.mjs`, checked by `npm run content-pack`.
Stories come straight from `server/data/scenarios.json` (id, title, takeaway), so the pack cannot drift from the scenarios; a test pins that.
Diagrams are empty until step IP1 (the ReactFlow page). Sources are marked `not-read`: the RFC links are cited from the PAR skill and standard knowledge, not re-read for this pack. The catalog id `C40` is a placeholder until the board assigns one.
